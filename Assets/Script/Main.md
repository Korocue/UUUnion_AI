# 設定
うにおんはミクスチャと呼ばれるアイテムに
インスピレーションをためて、生産行動を行います

# カメラ設定
カメラは画面上に配置されたうにおんを
遠くから眺めたり、回転させて眺めたり出来ます。
Assets\Script\Core\Camera\Camera.mdに従って
カメラを設定してください。

# 半減期つき指数移動平均（EMA, half-life EMA）
うにおんのミクスチャの処理は
「半減期つき指数移動平均(half-life EM)」を多用します。
EmaHalfLife.csに処理を記述してください。

# インスピレーションの設定
うにおんはミクスチャへミックスを行い
インスピレーションをためます。
Assets\Script\Core\InspCore.md に従って
インスピレーションのコーディングを行ってください。

# ミックスポップの設定
うにおんが使うのはミクスチャへミックスを行うための
ポンプのような円のオブジェクトです。
Assets\Script\Core\MixCore.md に従って
ミックスポップの設定をコーディングを行ってください。

# がまんの設定
ミクスチャに溜まったインスピレーションを
うにおんは「がまん」します。
Assets\Script\Core\GamanCore.mdに従って
そのがまん値の設定を行ってください。

# デバッグ機能
- Assets\Script\Core\Debug\Debug.md に従って
- デバッグ機能のコーディングを行ってください。
