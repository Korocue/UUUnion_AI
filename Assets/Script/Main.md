# うにうに飽和関数
インスピレーションによって決まる指数
「うにうに飽和」を実装してください。
- r = インスピレーション
- f(r) = (r^k) / (1 + (r^k))
- 「f(r) + f(1/r) = 1」という「対称性」を満たす
- カーブの鋭さは「k」は以下の通り
  - k = log2(3) ≈ 1.5849625
- インスピレーション100%の時 = 50%
- インスピレーション200%の時 = 75%
- インスピレーション50%の時 = 25%
になるような関数です。
