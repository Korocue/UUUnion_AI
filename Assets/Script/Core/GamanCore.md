# がまんの設定
Assets\Script\Old\Uni_Mxt_Old.cs.disabledを参考に
がまん値をコーディングしてください。

## がまん値のイメージ
InspPopにて、「がまん」はInspPopの内部の円として表現します。
- InspPopの上にGamanPopを配置して表現するので
- GamanPopが上に表示されるようにスプライトのオーダーを調整してください
表示される部分の面積が、Gaman値と同値になるようにします。
- GamanPopがInspPopを差し引く分、InspPopを加算します。
Gamanが0%に近づくと、円が黄色くなる(RGB(255, 255, 0))
Gamanが50%に近づくと、円が赤くなる(RGB(255, 0, 0))
Gamanが100%に近づくと、円が黒くなる(RGB(0, 0, 0))

## インスピレーション限界
インスピレーションには限界があります。
インスピレーションの限界の初期値を100%とします。

## がまんの影響
「がまん」によって、インスピレーションは圧縮されます。（今後実装予定）
- これはよりレベルの高い生産物を作るためです。
インスピレーションを抑えきれないとミクスチャはバクハツします。（今後実装予定）

## がまんの限界
「ミックス速度(半減型ミックス平均速度)」のしきい値を計算します。
インスピレーション限界（=100%）では、ミックス強度(=1%)に対して、秒間1回のミックスでバクハツ。
200%のインスピレーションでは、秒間0.5回のミックスでバクハツ。
50%のインスピレーションでは、秒間2回のミックスでバクハツ。
これが「がまんの限界」です。

## がまん値
がまんの限界に対する「ミックス速度」の割合(= A)は
半減期1分の指数移動平均に、
「1分あたりのミックス速度」として A/60 を加えます（= がまん値）。
> 1分間がまんの限界を超えるミックスを加えることで
> がまんの限界を越えます。
