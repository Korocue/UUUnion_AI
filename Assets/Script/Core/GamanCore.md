# がまんの設定
Assets\Script\Old\Uni_Mxt_Old.cs.disabledを参考に
がまん値をコーディングしてください。

## がまん値のイメージ
InspPopにて、「がまん」はInspPopの内部の円として表現します。
- InspPopの上にGamanPopを配置して表現するので
- GamanPopが上に表示されるようにスプライトのオーダーを調整してください
表示される部分の面積が、Gaman値と同値になるようにします。
- GamanPopがInspPopを差し引く分、InspPopを加算します。
GamanPopに大きさの制限はありません

### 色変化
Gamanが0%に近づくと、円が灰色になる(RGB(128, 128, 128))
Gamanが50%に近づくと、円が濃灰色になる(RGB(64, 64, 64))
Gamanが80%に近づくと、円が黒色になる(RGB(0, 0, 0))
Gamanが90%に近づくと、円が紺色になる(RGB(0, 64, 64))
Gamanが100%に近づくと、円が赤くなる(RGB(255, 0, 0))
Gamanが200%に近づくと、円が白くなる(RGB(255, 255, 255))
Gamanが300%に近づくと、円がピンク色(RGP(255, 0, 255))

## インスピレーション限界
インスピレーション限界、インスピ限界。
インスピレーションには限界があります。
インスピレーションの限界の初期値を100%とします。

## インスピ率
インスピ限界に対する、インスピ量の割合です。
インスピ限界の半分のインスピがあれば、0.5となります。

## がまんの影響
「がまん」によって、インスピレーションは圧縮されます。（今後実装予定）
- これはよりレベルの高い生産物を作るためです。
インスピレーションを抑えきれないとミクスチャはバクハツします。（今後実装予定）

## がまんの限界
「ミックス速度(半減型ミックス平均速度)」のしきい値を計算します。
インスピレーション限界（=100%）では、ミックス強度(=1%)に対して、秒間1回のミックスでバクハツ。
200%のインスピレーションでは、秒間0.5回のミックスでバクハツ。
50%のインスピレーションでは、秒間2回のミックスでバクハツ。
これが「がまんの限界」です。

## がまん値
がまんの限界に対する「ミックス速度」の割合(= A)は
半減期1分(60s)の指数移動平均に、
「1分あたりのミックス速度」として A/60 を加えます（= がまん値）。
> 1分間「がまんの限界」を超えるミックスを加えることで
> がまんの限界を越えます。

### ミックス耐性
以上を初期値として
- 半減期の秒数を(B)
  - (B)は「がまん値の逆数」を取り
    - 溜まれば溜まるほど、半減期が短くなります
    - (B)は100を越えない
    - 0除算を防ぐため、がまん値が1%以下の場合(B = 100)で固定される
  - この(B)をミックス耐性とします。
- (B)秒あたりのミックス速度として、A/B を加えるものとする
  - Bは必ず100以下（下限は0.1くらいが限度？）
- インスピ限界を超えると(B)が下がるため
  - がまんが非常に不安定になります（バクハツしやすい）

#### 例
- がまん率0-1%
  - ミックス耐性 = 100
    - 半減期100秒
- がまん率50%
  - ミックス耐性 ≒ 100 / 50
    - 半減期2秒
- がまん率100%
  - 半減期1秒
バクハツに近い状態は心臓の鼓動が速くなるイメージに近い
外力が弱ければすぐに収束するが、引き金が引かれ次第すぐ爆発する 

## バクハツ
仮実装です。がまん値が300%を越えたらバクハツ状態とし
インスピレーションを「生産量」として加算し、0にしてください。
これは重要な値の1つなので、インスピよりも上に表示してください。
