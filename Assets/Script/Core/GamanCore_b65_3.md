## がまん値のイメージ
InspPopにて、「がまん」はInspPopの内部の円として表現します。
- InspPopの上にGamanPopを配置して表現するので
- GamanPopが上に表示されるようにスプライトのオーダーを調整してください
表示される部分の面積が、Gaman値と同値になるようにします。
- GamanPopがInspPopを差し引く分、InspPopを加算します。
GamanPopに大きさの制限はありません

### 色変化
Gamanが0%に近づくと、円が灰色になる(RGB(128, 128, 128))
Gamanが50%に近づくと、円が濃灰色になる(RGB(64, 64, 64))
Gamanが80%に近づくと、円が黒色になる(RGB(0, 0, 0))
Gamanが90%に近づくと、円が紺色になる(RGB(0, 64, 64))
Gamanが100%に近づくと、円が赤くなる(RGB(255, 0, 0))
Gamanが200%に近づくと、円が白くなる(RGB(255, 255, 255))
Gamanが300%に近づくと、円がピンク色(RGP(255, 0, 255))

## インスピレーション限界
インスピレーション限界、インスピ限界。
インスピレーションには限界があります。
インスピレーションの限界の初期値を100%とします。

## インスピ率
インスピ限界に対する、インスピ量の割合です。
インスピ限界の半分のインスピがあれば、0.5となります。

## がまんの影響
「がまん」によって、インスピレーションは圧縮されます。（今後実装予定）
- これはよりレベルの高い生産物を作るためです。
インスピレーションを抑えきれないとミクスチャはバクハツします。（今後実装予定）

## がまんの限界
「ミックス速度(半減型ミックス平均速度)」のしきい値を計算します。
インスピレーション限界（=100%）では、ミックス強度(=1%)に対して、秒間1回のミックスでバクハツ。
200%のインスピレーションでは、秒間0.5回のミックスでバクハツ。
200%のインスピレーションでは、秒間0.5回のミックスでバクハツ。
50%のインスピレーションでは、秒間2回のミックスでバクハツ。
これが「がまんの限界」です。

## モード切替
試作として、がまんの計算方法を複数実装します
インスペクタでの切り替え機能をお願いします

## がまんモード1
モード名を「ZiwaZiwa」とします

### がまん値
がまんの限界に対する「ミックス速度」の割合(= A)は
半減期1分(60s)の指数移動平均に、
「1分あたりのミックス速度」として A/60 を加えます（= がまん値 / がまん率）。
> 1分間「がまんの限界」を超えるミックスを加えることで
> がまんの限界を越えます。

#### ミックス耐性
MixResist.mdに従い、
上記がまん値に対する「ミックス耐性」を実装します

## がまんモード2
モード名を「DokiDoki」とします

### がまん値
がまんの限界に対する「ミックス速度」の割合(= A)を
そのままがまん値に適用します
ただし、半減期1秒の指数移動平均に、Aを加えた量を差し引きます。
- 以上を初期値とし
  - 半減期の秒数を(B)とし、加える秒数を(A/B)とします
    - この差し引く値を「どきどき値」としてデバッグ表示をお願いします
      - 「どきどき値」はモード2での「ミックス耐性」に該当します
差し引いてマイナスになった分は、インスピポップが縮小します。
- がまん値は0を下限と「しません」
- ただし0以下のがまんポップはスケール0で実質非表示となります
  - その代わりの面積がインスピポップの面積から差し引かれます

うにおんの「ある程度のミックス速度に対して慣れる」という意味の挙動です
基本的にはずっと同じ速度でミックスしていると
- 慣れてミックスを感じづらくなります（ガマン値の平均が0に近づきます）

しかしそれに対して、少しずつインスピが溜まっていくことによって
根本的にこのどきどき値では抑えきれなくなっていきます。

#### 半減期の増加
ミックス速度の増加を消費して、半減期が増えます
A_Base = ベースミックス速度
C = f(A_Base) : 消費率
A_Use = A_base * (1 - c) : 実際に消費される速度(増加が抑えられる)


> f(r) = r^k / (1 + r^k)
> k = log2(3) ≒ 1.585
> r = ミックス速度（100% = 1）
> ミックス速度の消費（半減期の増加）率は、ミックス速度のべき乗に基づく飽和関数によって算出される。
> この関数は、一定値を境に効果が急増し、その後は漸近的に上限へ近づく特性を持つ。
> この関数は、ミックス速度100%を基準点として効果が急増し、
> その後は漸近的に上限へ近づく特性を持つ。
- 50% = 25% 
- 100% = 50%
- 200% = 75%
- この分、ミックス速度の増加が抑えられ、半減期(B)が増加します。

#### どきどき値減少
どきどき値は(B)で除算されます
