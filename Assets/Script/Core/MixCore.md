# ミックスの設定
うにおんのミックスに関する設定をしてください

# ミックスポップ
インスピポップの右下にミックスポップを配置します。
ミックス強度（デフォルトで1%）を示す、黄色い円が表示されます。

# ポンプ作業
ミックスは右ボタンを押したまま
マウスを上にドラッグすることで「ポンプ」します。
ドラッグ距離に比例して、100ピクセルにつき50%のスケールで円の「半径」を収縮させます。
- これは距離のべき乗に従って逓減します（100pxで50%、200pxで75%…）。
それに対して「面積で」中身をミックス値に変換し、最終的にインスピに変換します。

# ミックスポップの補充
消費したミックスは
- ポンプしていない分は 時定数0.2秒 の指数回復で補充される。
- ポンプ中の分も 時定数0.02秒 の指数回復で補充される。

# ミックスポップの色設定
0% = 白 RGB（1, 1, 1）
1% = 黄色 RGB (1, 1, 0)
