# ミックスの設定
うにおんのミックスに関する設定をしてください

# ミックスポップ
インスピポップの右下にミックスポップを配置します。
ミックス強度（デフォルトで1%）を示す、黄色い円が表示されます。

# ポンプ作業
右ボタンを押した状態でポンプ状態になります。
この状態でマウスを上に動かすことで「ポンプ」します。
マウスの上下移動でポンプレベルが上下し
ミックス残量に応じて円の半径、面積が変化します。

## マウスを上に動かすことで収縮
[100ピクセル]（※1）につき50%のスケールで円の「面積」を収縮させます。
- これは距離のべき乗に従って逓減します（100pxで50%、200pxで75%…）。
それに対して「面積で」中身をミックス値に変換し、最終的にインスピに変換します。
（※1に対して、インスペクタに値を設定できるようにお願いします。）

## マウスを下に動かすことで収縮解除
下にドラッグすることで、逆に100pxで50%の割合で元に戻ります。
ただし、この時の基準を「150%の面積（※2）」とします。
収縮した後の「面積」を(A)として、「150%-(A)」が距離のべき乗に従って逓減します。
**すなわち、ポンプレベルはマイナス50%までの値を取ります。**
（※2を100%以上の範囲で設定出来るようにしてください
　それに応じてポンプレベルの範囲も変わります）

## ポンプ状態の解除
ボタンを離すと、ポンプは止まります。
ポンプレベルは**時定数0.2秒**の速度で0に収束します。
ポンプレベルがマイナスの時に、100%を越えて溜まってしまった分が
ミックス値に変換される点に注意してください。
ポンプレベルに合わせて、ミックス残量も緩やかに変化します。

# 旧実装案です(無視してください)
```
## 基準点の補正
基準点はマウスを上下する度に補正がかかります。
(基準点のデバッグ情報をお願いします)

## 下方向の補正
マウスが下に下がりすぎる場合は
移動量に対して半分の割合で基準点を下げます。
クリックポイントからカーソルが下回った場合
-　たとえば下方向に100px動いた場合に、50px基準点を下げます。
-　下で止まり続けても、基準点は動きません
-  下がった基準点は基準点に戻っても上がるような挙動はしません。
  -  逆に基準点をさらに下回るまではそれ以上下がりません
-  基準点が動くのはあくまで「下方向のみ」で左右などは一切影響を受けません

## 上方向の補正
ミックスポップが「90%以上収縮」した場合は
-  これはポンプレベルで判定するようにしてください
-  同様に基準点を上方向に補正します
-　たとえば上方向に100px動いた場合に、50px基準点を下げます。
-　上で止まり続けても、基準点は動きません
-  上がった基準点は元に戻りません
```

# ミックスポップの補充
ミックスポップの大きさは
ポンプされていない状態でも補充されるまでは戻りません。

## 消費中のミックス
消費したミックスは2つの状態に分けられます。
（例としてポンプレベルが40%
  ミックスを70%消費し、30%残っているものとします。）

(A) ポンプ中を差し引いて回復可能な分（30%）
- 70%の消費のうち、40%はポンプ中なので差し引き30%が回復可能です
- このポンプしていない分（A = 30%）は
  - ポンプしていない分を上限に
  - **時定数0.2秒** の指数回復で補充されます。
- ポンプレベルがマイナスの場合は、上限を超えてポップが補充されます。

(B) ポンプ中なので回復不可能な分(40%)
- 70%の消費のうち、40%はポンプ中なので回復出来ません。
- それでもポンプ中の分（B = 40%）も **時定数2秒** の指数回復で補充されます。
  - (A)に対して(B)の回復量は10%の速度で、極めて低速度です。
  - 100%ポンプしている状態なら、100%に向けて**時定数2秒**の速度で補充され、すぐに消費されます。
  - 50%ポンプしている状態なら、50%の向けて**時定数2秒**の速度で補充され、すぐに消費されます。
  - 逆にマイナス値の場合は**時定数2秒**で補充が遅れます。

### 例
- たとえば円の面積が75%だったら、75%までを補充の上限とします
- 100%から75%に減った直後は、75%からの回復はしません（25%分の時定数2秒ルールのみ）

# ミックスポップの色設定
0% = 白 RGB（1, 1, 1）
1% = 黄色 RGB (1, 1, 0)
10% = 赤 RGB (1, 0, 0)

# デバッグに関して
ミックス関連値の表示を小数第6位までお願いします。
