# ミックス耐性
## ミックス耐性モード
- (モード1) がまん率補正のON/OFF
  - OFF時はインスピ率補正を除くミックス耐性を1で固定する
- (モード2) インスピ補正のON/OFF
- (モード3) がまんA値補正（排他的）ON/OFF
  - 現在は排他的とし、他の(1), (2)と共存しない(無効化、強制OFF)

## がまん率補正（モード1）
GamanCore.mdの「がまん値」の内容を初期値とし
- 半減期の秒数を(B)
  - (B)は「がまん値の逆数」を取り
    - 溜まれば溜まるほど、半減期が短くなります
    - (B)は100を越えない
    - 0除算を防ぐため、がまん値が1%（= 0.01）以下の場合「B = 100」で固定される
  - この(B)をミックス耐性とします。
- (B)秒あたりのミックス速度として、A/B を加えるものとする
  - Bは必ず100以下（下限は0.1くらいが限度？）
- インスピ限界を超えると(B)が下がるため
  - がまんが非常に不安定になります（バクハツしやすい）

### 例
- がまん率0-1%
  - ミックス耐性 = 100
    - 半減期100秒
- がまん率50%
  - ミックス耐性 ≒ 100 / 50
    - 半減期2秒
- がまん率100%
  - 半減期1秒
バクハツに近い状態は心臓の鼓動が速くなるイメージに近い
外力が弱ければすぐに収束するが、引き金が引かれ次第すぐ爆発する

## インスピ率補正（モード2）
InspModifier.mdに従い
「ミックス耐性」に対して、インスピ率補正を実装します。

## がまんA値補正（モード3）
GamanCore.mdでの「がまんの限界」に対するミックス速度（がまんA値）によって
ミックス耐性に補正をかける
- 最低値1（がまんA値 = 0% ～ 1%）の範囲。
- 「がまんの限界」とミックス速度が一致する(100%)の時に、ミックス耐性を100とする
- 50%の時に50とする
- 限界値は1000%でミックス耐性1000とする。

## ミックス耐性ポップ
ミックス耐性ポップを追加します。
インスピポップを抑え込むようにさらに外殻を覆います
- 面積の計算式
  - がまんポップ + インスピポップ + 補正値 = ミックス耐性ポップ
- 補正値(0～1) = (100 - ミックス耐性) / 100
  - 耐性がないと、インスピを激しく抑え込もうとします
  - 100に近づくほど、逆に小さくなる式を記述しています

### 色帯
補正値 = 
- 100% = 黒 RGB(0, 0, 0)
- 50% = 赤 RGB(1, 0, 0)
- 25% = 黄 RGB(1, 1, 0)
- 0% = 白 RGB(1, 1, 1) 

色帯が正しく反映されていないので
補正値に合わせて色を調整してください。
- インスピ耐性が100の時、補正値は0%に近づき、白
- インスピ耐性が1に近いほど、補正値は100%に近づき、黒へ
