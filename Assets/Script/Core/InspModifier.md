
# インスピ率ミックス耐性補正
MixResist.mdによって定義される「ミックス耐性」に対し
- インスピ限界に近ければ近いほど、補正がかかる
- すなわち「うにおんはインスピが高いほど慣れる」
  - 慣れるとミックス耐性が100に近づく（戻る）
  - ミックス耐性に対し、(100 - ミックス耐性)を指定の量「足し直す」。

(A)逆数方式
- インスピ率が100%に近づくと、ミックス耐性は100に戻る
  - インスピ率が50%では、ミックス耐性が2%戻る
  - インスピ率が75%では、ミックス耐性が4%戻る
  - インスピ率が90%では、ミックス耐性が10%戻る

(B)正規方式
- インスピ率が100%に近づくと、ミックス耐性は100に戻る
  - インスピ率が50%では、ミックス耐性が50%戻る
  - インスピ率が75%では、ミックス耐性が75%戻る
  - インスピ率が90%では、ミックス耐性が90%戻る
  - (B)では補正値に上限なし
    - ミックス耐性はさらに上がり続ける

(C)飽和方式
> f(r) = r^k / (1 + r^k)
> k = log2(3) ≒ 1.585
> r = インスピ率（100% = 1）
> 回復率は、インスピ率のべき乗に基づく飽和関数によって算出される。
> この関数は、一定値を境に効果が急増し、その後は漸近的に上限へ近づく特性を持つ。
> この関数は、インスピ率100%を基準点として効果が急増し、
> その後は漸近的に上限へ近づく特性を持つ。
- インスピ率が50%で、ミックス耐性は25%戻る
  - インスピ率が100%で、ミックス耐性は50%戻る
  - インスピ率が200%で、ミックス耐性は75%戻る

実験のため上記の(A), (B), (C), OFFを切り替えられるようにする。
- 補正方式を enum で定義
- OFF / A(逆数) / B(線形) / C(飽和) をインスペクタのプルダウンで切り替える。
- 補正値をデバッグ表示する
